# 전투 AI와 복수 로얄 규칙

## 규칙

- 권총: 기존 기본 명중률 100%, 인접 칸 기준으로 한 칸 멀어질 때마다 10%p 감소. 사거리 7칸 유지.
- 소총: 거리 0 기준 100%, 실제 거리 한 칸당 5%p 감소. 인접 칸 95%, 6칸 70%. 기존 사거리 6칸 유지. 따라서 표의 7칸 65%는 수식상의 값이며 실제 공격은 불가능하다.
- 살아 있는 적 로얄을 모두 포획하면 승리한다. 기존 몬스터의 로얄 수는 원래 설계대로 유지한다. 쌍둥이 신과 두 창고를 목표로 하는 전투만 두 로얄을 사용하며, 랍스타와 템페스트 폰은 전투마다 한 기를 무작위로 지정한다. 아군 킹 패배 조건은 그대로다.
- 새로운 몬스터를 설계할 때의 로얄·호위 기준은 이미 구현된 몬스터의 편성에 소급 적용하지 않는다. 최종 결전은 부족의 독재자 한 기만 배치한다.

## 탐색

`ai.rs`는 `Battle::legal_actions`에서 Chesssembly 및 기물별 특수 행동을 생성하고, `Battle::apply_piece_action_unchecked`로 이미 판정된 행동을 시뮬레이션한다. 탐색 중 실제 턴이 바뀔 때만 Negamax 부호와 턴 깊이를 바꾼다. 같은 턴의 추가 행동은 행동 수 상한으로 제한한다. 적은 현재 카드 사용자가 아니므로 카드를 생성하지 않는다.

반복 심화, Alpha-Beta, PVS, 상태 해시 기반 전이표, 이전 수와 포획 가치 기반 수 정렬, 포획 연장 탐색을 사용한다. 명중·빗나감은 확률 가중 기대값으로 합치며, 시체 효과와 종소리 목표는 가능한 결과를 최대 세 개까지 전개한다. 각 결과는 별도의 전투 상태에서 계산한다. 프로그램 파싱 결과는 전투 복제 간 공유한다.

| 전투 | 노드 상한 | 최대 턴 깊이 |
|---|---:|---:|
| 일반 | 90 | 2 |
| 엘리트 | 280 | 3 |
| 보스 | 800 | 4 |

예산이 소진되면 마지막으로 완료한 깊이의 수를 사용한다. 첫 깊이도 완료하지 못했다면 합법 수 중 정렬 최상위를 사용한다. 웹은 Worker에서 추천 수를 계산하고, 메인 스레드에서 해당 합법 행동의 인덱스를 검증하여 적용한다. 저장 명령도 이 인덱스를 기록한다.

상대적인 강도는 예산 차이로 설정했으며 Elo 수치는 아직 실전 대국으로 측정하지 않았다. 평가 함수는 로얄 생존, 기물 가치, 활동성, 민첩, 가호, 약화를 반영한다. 플레이어 손패와 카드 사용 가능성은 현재 적 AI 탐색에 포함하지 않는다. 종소리 목표가 넷 이상이면 세 결과를 표본으로 사용한다.

## 몬스터 성향과 초기 진형 점검 (2026-10-30, 이전 편성 기록)

같은 탐색 엔진에서 일반·엘리트는 공격형 평가를 사용한다. 기물 재료값의 가중치를 낮추고 중앙 활동성과 상대 로얄에 접근하는 압력을 높였다. 로얄 포획은 이미 종료 점수로 처리되므로 공격형에서는 별도의 로얄 보존 점수를 두지 않는다. 보스는 기존보다 높은 재료값과 인접 호위·로얄 생존 점수를 사용한다. 탐색 예산은 위 표를 유지한다.

아래 수치는 임시로 재편한 진형에서 측정한 과거 기록이며, 복원된 기존 몬스터의 현행 난이도를 나타내지 않는다. 기물 `value=10`을 폰 1점으로 잡고, 정적 평가를 공격형은 90점, 보스 방어형은 120점당 폰 1점으로 환산했다. 기본 수호자 16기, 카드·유물 미사용 기준이다. 양수는 플레이어 우세다.

| 전투 | 초기 평가 | 24행동 탐색 대국의 교환 (아군 손실 / 적 손실) |
| --- | ---: | ---: |
| 1F-N01 홀로 선 왕 | +41.5 | 2 / 0 |
| 1F-E01 마하라자 | +5.1 | 6 / 5, 아군 승리 |
| 1F-E03 건어물 | 원래 16기 배치 복원으로 재측정 필요 | 기존 3폰 배치에서 5 / 4 |
| 2F-E01 템페스트 건어물 | +4.6 | 5 / 4 |
| 2F-B03 영원한 주빈 | -9.5 | 7 / 4 |
| 3F-E01 보급기지 | +7.2 | 5 / 6 |
| 3F-B01 포병대대 | -2.6 | 9 / 1 |
| 4F-B01 특수부대 | -7.3 | 6 / 1 |
| FINAL-B01 부족의 독재자 | +23.7 (HP·습득 능력 미반영) | 미측정 |

탐색 대국은 두 진영 모두 카드 없이 50노드·2턴 예산의 AI로 최대 24행동을 둔 단일 표본이다. 경기 결과의 대리 지표이며 승률은 아니다. 사격 위주의 3·4층은 정적 점수보다 아군 손실이 커서 실제 플레이와 여러 시드의 추가 검증이 필요하다.

## 검증

- `cargo test --workspace`: 기존 몬스터 편성과 로얄 ID, 복수 로얄 생존·종료, 페어리 기물 합법 수, 사격 선택과 명중률을 확인한다.
- `npm run build`: TypeScript와 Worker 포함 프로덕션 빌드를 확인한다.
- `npm run test:e2e -- enemy-worker.spec.ts`: 브라우저 Worker의 선택, 메인 스레드 진행, 저장 재생을 확인한다. Playwright 실행에는 로컬 Vite 서버를 열 수 있어야 한다.
