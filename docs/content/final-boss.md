# 최종 보스: 부족의 독재자

최종 결전(`DICTATOR_BOSS`)에는 적 기물로 독재자 한 기만 배치한다. 독재자의 HP가 0이 되면 전투가 끝난다.

- 시작 HP는 5이며 상한이 없다. 독립적인 제거 판정마다 HP가 1 감소한다. HP가 남으면 기물은 그 자리에 남는다.
- 주변 8칸의 실제 사망마다 HP가 1 증가하고 사망한 기물 종류의 행마와 사용 가능한 특수 행동을 전투 종료까지 배운다. 시체로 바뀌는 순간과 나중에 그 시체가 제거되는 순간은 각각 한 번의 사망이다.
- 기물 공격으로 HP가 감소하면 마지막 공격자의 ID를 갈고리 대상으로 저장한다. 다음 적 턴 시작 시 독재자 주변의 빈칸으로 끌어온다. 대상이 사라지거나 빈칸이 없으면 실패한다.
- 샷건은 2발 장전되며 사격당 1발을 쓴다. 방향 하나를 고르면 그 방향과 좌우 45도에 한 탄도씩 발사한다. 각 탄도는 최대 3칸에서 처음 만난 기물만 판정하며 아군도 맞는다. 명중률은 1·2·3칸에서 100·75·50%이고 일반 사격 판정 경로를 쓴다. 빈 탄창의 재장전은 사격 대신 사용한다.
- 플레이어 턴이 시작되기 전에 독재자의 최대 두 행동과 순서를 고정한다. 보드에는 남은 두 행동의 위험 칸과 목표를 표시하며, 이동 뒤 사격 범위는 예정된 이동 위치에서 계산한다. 목표가 사라지거나 행동이 불가능해지면 그 행동 기회만 소모하고 다른 행동으로 교체하지 않는다. 갈고리는 별도 반응이다.
- 독재자는 적 턴마다 이동·포획 1회와 제자리 사격·재장전·습득 능력 1회를 사용할 수 있다. 순서는 AI가 정하며, 빈 사격처럼 이득이 없는 행동은 생략한다. 같은 종류를 두 번 사용할 수 없으며, 민첩으로 추가 행동을 얻지 않는다. 시체 섭취 등 별도 능력의 강제 턴 종료는 유지한다.

## 기존 엔진 재사용

행마는 사망 기물의 등록된 이동 스크립트나 native 이동 생성기를 다시 호출한다. 습득한 특수 행동은 해당 기물 종류를 전투 행동 동안 적용해 기존 사격, 자폭, 희생, 시체 처리 코드로 실행한다. HP 피해는 실제 제거와 구분하고, 실제 사망 때만 제왕학과 회복을 처리한다. 카드, 폭발, 사격, 일반 포획 모두 기존 제거 경로와 결과 판정을 사용한다.

## 전투 연출

Rust의 `combat_events`는 명령마다 초기화되는 실제 판정 결과다. 샷건은 탄도별 첫 장애물까지의 칸과 명중·빗나감·가호·시체 변환을 기록한다. 범위 미리보기와 실제 사격은 같은 탄도 계산을 사용하며, 발사 도중 발생한 연쇄 폭발로 다음 탄도가 달라지는 경우도 결과에 반영한다. 웹은 이 칸을 짧게 강조하고, 같은 총구에서 각 탄도 끝점으로 퍼지는 장식용 산탄을 표시한다. 탄환 수는 추가 판정을 만들지 않는다.

사슬 이벤트는 끌어오기 성공 시에만 보스 위치·대상 ID·출발/도착 칸을 기록한다. 웹은 공격 피격 → 고리 사슬 확장 → 연결 → 끌어오기 순서로 재생한다. 표시용 중간 위치만 별도로 유지하며 엔진 상태는 이미 확정되어 있다. 동작 줄이기 설정과 저장 재개는 즉시 확정 상태를 표시한다.

보드 하단의 `boss-intent-panel`은 제거했다. HP는 보드 위 오른쪽의 별도 `보스 체력` 표시에서 큰 숫자로 확인한다. HP 상한이 없으므로 최대 체력 비율을 표시하지 않는다. 탄약·다음 행동은 제목 영역, 목표와 위험 칸은 보드, 습득 능력은 기물 상세 정보에서 확인한다.

## AI 선정

이전 최종 보스는 `ai.rs`의 탐색을 우회하고 `plan_boss`의 점수표로 행동했다. 샷건은 대상의 기물 가치나 로얄 여부 없이 명중률을 합산했고 아군 피격에도 +8점을 줬다. 따라서 인접 폰 두 기(220점)를 거리 3의 로얄(70점)보다 선호하고, 아군만 맞히는 사격(28점)을 이동(최대 16점)보다 선호했다. 실제 행동 뒤의 HP·회복·습득·사슬·승패도 평가하지 않았다.

현재는 다음 적 턴을 엔진 복제 상태에서 시작해 합법 후보를 얻고, 각 후보와 남은 행동의 실제 결과를 먼저 평가한다. 이동으로 사거리에 들어온 뒤 사격하는 이득도 이 단계에서 반영한다. 이후 두 행동 선정이 보스 예산인 800노드·최대 4턴 탐색을 공유한다. 최종 보스 전용 평가는 HP·탄약·습득 능력·로얄 압박을 반영한다. 산탄은 엔진이 실행 중 보고하는 각 명중 확률에 따라 최대 8가지 결과를 계산하며, 연쇄 효과와 난수 진행도 유지한다. 후속 행동 예고는 진행 가능한 확률 분기 중 대표 상태에서 정하며 실제 미래 난수를 읽지 않는다. 일반 몬스터·엘리트의 평가 방식은 그대로다.

행동 예고 고정과 회피 시 실패 규칙은 유지한다. 저장 복원 시에는 기록된 합법 행동 인덱스를 사용해 과거 보스 행동을 재생하므로, AI 개선으로 기존 웹 저장의 과거 행동이 바뀌지 않는다. 진행 중 명령은 계속 예고된 행동만 실행한다.

## 현재 표현하지 못하는 상시 효과

기존 기물의 **전투 시작 시 부여되는 상태**(예: 정찰병의 민첩, 특수 지휘관의 가호)와 **상시 오라 및 라운드 자동 효과**(예: 영원의 손님의 종소리)는 기물 종류를 직접 검사하거나 전투 시작 때만 설정된다. 제왕학은 이 효과들을 새로 부여하지 않는다. 행마와 행동 시 발동하는 능력은 복제된다. UI의 습득 목록에는 원본 기물 설명을 표시해 이 차이를 검토할 수 있다.

## 확인 방법

1. `cargo test -p chesslayer`로 HP, 시체 전환, 갈고리, 3갈래 사격, 복제 자폭, 예고 고정 및 기존 전투 회귀를 확인한다.
2. `cd web && npm run wasm && npm run build`로 최신 엔진을 웹에 반영한다.
3. `cd web && npx playwright test tests/final-boss.spec.ts tests/combat-animation.spec.ts`로 상태 표시, 실제 샷건 범위, 사슬 이동, 입력 잠금, 동작 줄이기를 확인한다.

저장 명령 스트림의 규칙 버전은 20이다. 버전 19 저장은 과거 명령 구간을 기존 보스 1행동 규칙으로 재생한 뒤 새 규칙으로 이어간다. 이전 구간의 경계를 저장하므로 이후 재접속해도 같은 상태를 복원한다. 효과 대상 선택 도중의 저장은 선택 완료까지 기존 행동을 유지한 뒤 새 계획을 만든다. 버전 17·18은 편성과 로얄 수 규칙이 달라 이어받지 않으며, 원본은 새 원정을 시작하기 전까지 보존한다.
