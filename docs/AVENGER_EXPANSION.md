# 콘텐츠 확장 · v0.3.4

작업 브랜치: `feature/avenger_army`. 제공된 「Chesslayer 콘텐츠 확장 기획서 v0.2」와 대화에서 확정한 일곱 규칙을 반영한다.

## 확정 규칙

- 캐슬링: 같은 행·열에서 로얄이 메이져 쪽으로 2칸, 메이져는 로얄이 지나온 칸으로 이동한다. 사이 경로가 비어 있어야 하며 거리는 3칸 이상이다. 즉시 턴 종료.
- 알레킨의 총: 맨 앞 룩보다 전방인 해당 파일과 양옆 파일을 보드 끝까지 제거한다.
- 아-자-자-잣!!!: 룩-룩-퀸을 희생하고 맨 앞 룩 바로 전방부터 4개 랭크 전체를 제거한다.
- 일반 공격 후 대상이 생존하면 공격자는 출발 칸에 남는다. 공격에 사용한 행동·행마권은 소모한다.
- 전능: 적 로얄이 아군 마지막 랭크(1랭크)에 도착하는 즉시 패배한다. 아군 로얄 제거만으로는 패배하지 않는다. 변경된 적 로얄에도 적용하며 AI도 이 목표를 평가한다.
- 프리셋: 영구 기물 ID의 원래 배치 슬롯을 유지해 강화된 종류·이력도 보존한다. 프리셋에 없는 추가 기물은 비어 있는 원점, 이후 아군 후방부터 빈 칸에 배치한다.
- 신성: 사용 전 보드를 기준으로 각 아군의 유효한 강화 경로를 시드 기반 균등 추첨한다. 영구 로스터의 기물은 영구 강화하고, 전투 중 생성한 기물은 해당 전투에서 강화한다. 최종 단계 기물은 유지한다.

## 공통 전투와 복수귀

현재·최대 체력, 공격력, 기물 분류·점수, 행마권, 비무장과 임시 이름을 전투 상태로 관리한다. 기본 체력·공격력은 1이고 기존 독재자 보스는 고유 체력 규칙을 유지한다. 원래 기물 종류와 임시 이름을 모두 포지션 조건에 사용할 수 있다. 로얄 지정은 종류·분류와 독립적이다.

복수귀는 수호자 로스터·강화 트리, 시작 마나 3, 호신용품으로 시작한다. 시작 덱의 미지정 매수는 폰 행동명령 4장, 마이너 행동명령 4장, 메이져 행동명령 2장으로 구성했다. 첫 턴을 포함해 턴이 돌아올 때마다 5장을 뽑고, 턴 종료 시 사용하지 않은 손패를 모두 묘지로 보낸다. 드로우 도중 덱이 비면 묘지의 모든 카드를 셔플해 덱으로 되돌린다. 손패 한도는 10장이다.

일반 행마는 행마권을 소비하고 턴을 자동 종료하지 않는다. 적에게 부여한 행마권으로 적을 직접 조작할 수 있다. 고유 특수 능력의 사용 제한은 별도로 적용한다. 캐슬링·앙파상만 즉시 턴을 끝낸다. 미사용 행마권과 임시 이름·능력치는 플레이어 턴 종료 시 해제한다. 다음 적 턴 비무장은 적 턴 종료 시 해제한다.

기본 3장과 보상 32장, 총 35종 카드를 등록했다. 일반 카드 보상은 54/30/15/1% 희귀도 추첨을 사용하며 복수귀의 보스 보상은 전설만 등장한다. 기존 부대 카드의 희귀도는 비용 0~1/2/3/4 이상을 일반/희귀/영웅/전설로 대응한 초기 분류이며 후속 밸런싱 대상이다. 해당 희귀도가 없는 부대는 적용 가능한 카드 풀로 대체 추첨한다.

프리셋과 실시간 포지션 판정은 분리했다. 궁궐농밀과 알레킨의 총구는 기획서의 16개 좌표를 사용한다. 최근 획득 프리셋만 적용하고, 설탕 계열의 초기 마나는 4로 고정한다. 소멸은 전투 제외이며 영구 덱 삭제가 아니다. 임시 폰은 전투 종료 시 사라지지만 로얄로 지정한 폰은 영구 로스터에 편입한다.

## 이벤트

엠부쉬, 룰렛, 운수 좋은 날, 운수 나쁜 날, 히든, 보급품 상자, 폐기물 처리장을 기존 식당과 함께 추첨한다. 동일 사건의 연속 출현을 막고 대상·보상 가능 여부를 검사한다. 선택 후 결과를 확인하고 지도에 복귀한다.

- 엠부쉬는 원정당 1회이며 1층 보스 규칙을 사용한다. 승리하면 45골드와 영웅 이상 카드 선택을 제공한다. 층 진행·보스 해금·처치 기록을 올리지 않는다.
- 운수 좋은 날은 부대 보상 카드 15장을 카드 단위 균등 추첨한다. 중복을 허용하며 한 장만 획득한다.
- 운수 나쁜 날은 골드 절반(올림), 비로얄 죽음의 문턱, 다음 전투 첫 손패·초기 마나 감소 중 적용 가능한 선택지를 제시한다.
- 히든은 진입 시 결과 종류를 공개하고 희생·영구 손실을 실행 전에 안내한다.
- 추가 이벤트의 나머지 다섯 종류는 기획서의 후속 구현 대상이다.

## 일반전 및 무한 모드

일반전은 기존 특수 기물을 유지하면서 폰 방어선, 메이져 수비 기물과 소수 마이너를 보완한다. 추가 룩은 폰 방어선 뒤에서 로얄을 지원한다. 일반 AI는 로얄 방어와 교환을 더 중시한다.

무한 모드는 기존 15단계 지도와 보스를 유지한다. 16단계부터 추가 기물, 31단계부터 일부 체력, 46단계부터 메이져·특수 강화, 61단계부터 일부 공격력이 증가한다. 91단계부터 강화 효과 두 종류, 이후 세 구간마다 효과 수를 늘려 최대 8종을 적용한다. 추가 배치는 적 후방 4랭크의 빈 칸만 사용한다. 기존 특수 기물과 로얄의 위치는 보존한다.

체력·공격력 증가는 세 구간(45단계)마다 반복된다. 강화 엘리트·보스는 실제 노드 종류에 적용하고, 46단계 이후 구간의 3번째·12번째 전투에는 복합 부대·위험 진형을 적용한다. 지도 진입 전과 전투 중 강화 설명을 표시한다. 휴식에서는 강화·부활 외에 무료 카드 소각과 미보유 유물로의 교체를 선택할 수 있다.

최고 도달 단계, 부대, 달성 시각, 보스 처치 수, 덱 크기와 유물 수를 로컬 기록에 저장한다. 캠페인·무한 원정 저장을 분리하며 개발자 원정은 최고 기록을 갱신하지 않는다. 저장소를 사용할 수 없어도 플레이를 계속할 수 있다.

## 검증과 밸런스 지표

```sh
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo run -p chesslayer --example expansion_balance --release
npm run wasm --prefix web
npm run build --prefix web
CHESSLAYER_CHROME=/usr/bin/google-chrome npm run test:e2e --prefix web
```

검증 결과: Rust 224개 통과, 브라우저 83개 항목 통과(전체 실행 및 수정 항목 재검사 포함), Clippy 경고 없음, WASM·웹 프로덕션 빌드 성공. 웹 번들에는 기존 500 kB 크기 안내가 남아 있다.

`tests/avenger.rs` 및 `game/expansion_tests.rs`는 행마권·피해·비무장·특수 능력·로얄 교체·신성·전능·포지션·강제 제거·보상 확률·이벤트 재현·고단계 배치 경계를 검증한다. 브라우저에서는 실제 WASM 저장으로 카드 사용, 수동 턴 종료, 재개, 모바일 보드와 무한 기록을 검증한다.

균형 탐색 예제는 네 층 일반전 16종, 고정 시드 2026, 카드 없는 단순 탐욕 플레이어, 60턴 제한으로 비교한다.

| 지표 | 기존 배치 | 방어 배치 |
|---|---:|---:|
| 첫 턴 승률 | 0% | 0% |
| 평균 관측 전투 턴 | 18.69 | 19.00 |

로얄 생존 턴의 관측값은 전투 종료 또는 제한 턴에서 잘린 값이다. 이 결과는 단순 봇의 한 표본으로, 실제 플레이 난이도 검증을 대체하지 않는다. 방어 배치에서 아군 손실이 커지므로 부대별 플레이 테스트로 추가 조정해야 한다.
