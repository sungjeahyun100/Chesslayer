# 프로토타입 플레이 범위와 임시 결정

이 문서는 **첫 플레이테스트의 교체 가능한 임시 규칙**입니다. 정식 게임 규칙 확정을 의미하지 않습니다.

## 실제 플레이 루프

세 캐릭터 모두 일반 체스의 백 기물 16개로 시작합니다. 선봉대는 가속, 방랑자는 소용돌이, 수호자는 호신용품을 갖습니다. 캐릭터 고유 능력이나 별도 덱은 아직 없습니다. 새 원정마다 브라우저에서 새 시드를 받아 제1막 전체 맵을 생성합니다. 동일한 시드와 명령은 같은 지도·드로우·적 행동을 재현합니다. UI에는 시드 입력 기능이 없습니다.

진행은 전체 지도를 보고 연결된 다음 노드를 고르는 방식입니다. 일반 적 편성은 `e8 킹`, `e8 로얄 나이트`, `c8/f8 비숍과 e8 킹`, `a7~h7 폰과 e8 킹`입니다. 엘리트는 `e8 로얄 나이트 + c8/f8 비숍 + d7/f7 폰`, 보스는 `e8 로얄 아마존`입니다. [맵 규칙](ACT_MAP.md)에 노드 배치와 보상을 설명했습니다. 적은 항상 흑이고 플레이어가 먼저 행동합니다. 소용돌이가 있으면 이 시작 위치들이 적들 사이에서 바뀝니다.

승리 후 세 카드 중 하나를 반드시 보상으로 선택합니다. 일반전과 엘리트는 같은 세 종류를 제시하고 중복 획득을 허용합니다. 엘리트는 유물도 줍니다. 선택한 경로에 따라 전투 횟수와 보상이 달라집니다. 마지막 보스를 잡으면 보상 대신 원정 승리 화면을 표시합니다. 다음 전투 전에 아군을 재배치하는 단계는 없습니다.

## 전투와 로얄

- 적의 지정 ID가 로얄입니다. 킹 외에도 나이트·아마존이 될 수 있습니다.
- 일반 기물 액션으로 적 로얄을 직접 포획하면 승리합니다. 플레이어의 킹 포획은 패배입니다.
- 체크 제한, 체크메이트, 스테일메이트 승패, 캐슬링, 앙파상, 자동 승격은 기존 엔진과 마찬가지로 없습니다.
- 합법 수가 없는 적은 턴을 넘깁니다. 플레이어도 `턴 종료`가 가능합니다. 양측이 막혀도 자동 무승부는 없습니다.
- 전투 종료 시 생존 위치·종류·이동 이력·강화·지속 상태와 죽은 기물 기록을 유지합니다.
- 새 적의 배치와 겹친 아군은 가호와 관계없이 역습으로 제거됩니다. **킹의 역습 사망도 패배**입니다. 이 종료 원인은 직접 포획과 별도로 기록합니다.
- 카드와 유물의 비포획 제거는 **양측 로얄을 보호**합니다. 기존의 해결된 카드 액션 API도 로얄이 사라지는 효과를 원자적으로 거부합니다.
- 소용돌이 적용 → 충돌·역습 → 호신용품 반격 → 종료 판정 → 카드 전투 상태 생성 순서입니다. 역습으로 즉시 패배하면 생성된 카드 전투 상태도 정리합니다.

## 카드

영구 시작 덱 10장은 청바지 1장, 가호 6장, 알레킨의 총 1장, 찰나의 가호 2장입니다. 각 카드 사본은 서로 다른 ID를 갖습니다.

| 카드 | 비용 | 효과 | 프로토타입 키워드 |
| --- | --- | --- | --- |
| 청바지 | 0 | 양 진영의 룩·퀸 제거. 아마존은 메이저 분류에 넣지 않음. 양측 로얄 제외 | 선천성, 소멸 |
| 가호 | 1 | 선택한 백/흑 기물의 다음 일반 포획 1회 방어. 공격 전체가 취소되고 공격자는 제자리에 남지만 행동 횟수는 사용 | 일반 카드 |
| 알레킨의 총 | 3 | 아래의 진형 조건과 제거 범위를 적용 | 보존 |
| 찰나의 가호 | 0 | 가호와 동일한 효과를 가진 키워드 검증용 변형 | 휘발성 |

가호는 중첩되지 않습니다. 다시 사용하면 1회 보호 상태를 유지합니다. 아군에 남은 가호는 지속 상태로 계승됩니다. 방어한 가호는 즉시 제거됩니다. 카드 제거와 역습은 일반 포획이 아니므로 가호로 막을 수 없습니다.

전투 시작마다 영구 덱을 셔플합니다. 선천성은 첫 드로우 우선권이며 첫 손패 크기를 늘리지 않습니다. 내 턴 시작마다 마나를 3으로 설정하고 5장을 뽑되 손패 최대 10장까지만 받습니다. 남은 카드는 드로우 더미에 둡니다. 드로우 더미가 비면 버림 더미를 셔플합니다. 소멸 더미는 재셔플하지 않습니다.

일반 카드는 사용 후 버림, 소멸 카드는 사용 후 소멸입니다. 턴 종료 때 휘발성의 미사용 카드를 먼저 소멸시키고, 보존 카드를 남기며, 나머지를 버립니다. 가속의 첫 이동 후에는 턴이 끝나지 않으므로 카드 사용이 가능합니다. 실제 턴이 넘어갈 때만 손패를 정리합니다. 전투가 끝나면 모든 일시 더미·마나를 비우고 다음 전투에서 영구 덱으로 다시 만듭니다.

### 알레킨의 총: 임시 조건

백의 전방은 8랭크 방향입니다. **전방부터 룩–룩–퀸이 같은 파일의 연속된 세 칸**에 있어야 합니다. 맨 앞 아군 룩을 대상으로 선택합니다. 예: d5 룩, d4 룩, d3 퀸.

발사 범위는 맨 앞 룩보다 앞쪽의 모든 랭크와 중심 파일 양옆 1개 파일입니다. 위 예에서는 c6/d6/e6부터 c8/d8/e8까지입니다. 장애물 뒤에도 적용하고 아군도 제거합니다. 발사 진형 자체와 양측 로얄은 제거하지 않습니다. 가장자리에서는 보드 안의 파일만 적용합니다. 빈 범위에도 사용할 수 있습니다.

변경 위치는 `content/cards/gun.rs`의 `GUN_ADJACENT_FORMATION`, `GUN_HALF_WIDTH`, `GUN_HITS_ALLIES`와 `front()`입니다. 비연속 진형 허용 시에도 중간에 다른 기물이 끼면 진형을 인정하지 않습니다.

## 유물·휴식

| 유물 | 임시 동작 |
| --- | --- |
| 가속 | 양 진영 모두 턴당 최대 2회 이동. 같은 기물도 두 번 이동 가능. 남은 행동은 턴 종료로 포기 가능. 카드·마나 회복은 개별 행동이 아닌 턴 기준 |
| 소용돌이 | 적들이 점유할 예정인 칸의 집합은 유지하고 적 ID와 위치의 대응만 시드 기반 셔플. 1기일 때나 같은 순서가 나오면 보이는 변화가 없을 수 있음 |
| 호신용품 | 역습으로 아군이 죽은 칸의 적도 제거. 적 로얄은 남음. 킹의 역습 사망을 막거나 되돌리지 않음 |

가속 횟수는 `content/mod.rs::HASTE_ACTIONS`, 드로우 수·손패 상한과 마나는 같은 파일의 상수에서 교체할 수 있습니다. 시작 덱 구성은 `content/cards/mod.rs::starter_deck()`에 있습니다. 시작 유물 1개에 더해 보물과 엘리트에서 유물을 얻습니다. 이미 가진 유물은 중첩하지 않고 가호 카드 1장으로 바꿉니다. 유물 효과는 다음 전투부터 적용됩니다. 상점은 없습니다.

경로에서 선택한 각 쉼터마다 한 번 선택합니다.

- 강화: 살아 있는 일반 폰을 템페스트 폰으로 바꿉니다. 기존 폰 행마에 좌우 한 칸 이동·포획과 후방 한 칸 비포획 이동을 더한 임시 정의입니다. 첫 두 칸 전진 조건은 기존과 같습니다.
- 부활: 죽은 비킹 아군을 처음 원정을 시작했던 칸으로 복원합니다. 다른 생존 아군이 점유하면 거부하며 휴식 선택권을 사용하지 않습니다. 종류·강화·이동 이력·지속 메타데이터는 보존합니다.
- 아무것도 하지 않고 출발할 수 있습니다.

## 미구현 및 알려진 한계

- 2층 이후 콘텐츠, 상점·비밀방·랜덤 이벤트, 추가 기물 시리즈, 계정·멀티플레이·서버 저장은 제외했습니다.
- 저장·불러오기, 실행 취소, 원정 중 재시작 메뉴는 없습니다. 브라우저 새로고침으로 처음부터 시작할 수 있습니다.
- AI는 킹 포획과 포획할 기물 가치만 평가합니다. 교환 계산·킹 안전 분석·체크메이트 탐색을 하지 않습니다. 보스와 밸런스는 플레이테스트용입니다.
- 시드와 맵은 매 원정 새로 정하지만, 카드 보상 종류와 시작 덱은 고정 콘텐츠입니다. 전투·엘리트 편성 수가 적어 같은 편성을 여러 번 만날 수 있습니다. UI에 시드 변경이나 몬스터 선택 등 디버그 조작은 없습니다.
- 청바지는 초기 적보다 아군에게 더 불리할 수 있고, 알레킨의 총은 진형을 만드는 데 시간이 걸립니다. 보존 카드가 쌓이면 드로우 공간이 줄어듭니다. 카드 성능 조정은 아직 하지 않았습니다.
- 오래된 모바일이나 브라우저별 유니코드 체스 글꼴은 다르게 보일 수 있습니다. 아마존은 퀸+작은 나이트 표시, 템페스트 폰은 번개로 구분합니다. 정식 에셋은 없습니다.
- 작은 화면에서는 전체 지도를 위아래로 스크롤해서 봅니다. 카드 더미가 가로 스크롤되며, 보드와 손패 사이에 세로 스크롤이 필요합니다. 대상 카드 선택 시 보드로 이동합니다.
- 최근 60개의 플레이 기록만 표시합니다. 내부 실행 추적·디버그 패널·임의 상태 조작은 제공하지 않습니다.
