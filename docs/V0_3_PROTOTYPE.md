# Chesslayer v0.3.0 — 진행 프로토타입

> 이 문서는 **현재 별도 프로토타입 브랜치에서 실제로 동작하도록 연결한 부분**과 **임시 데이터로 대체한 부분**을 분리한다. 미완성 기믹을 확정 규칙으로 취급하지 않는다.

## 실제 연결한 진행 흐름

- 신규 런은 플레이어가 선택한 부대와 해금된 시작 구간으로 시작한다.
- 기본 해금 상태는 **수호자 부대 + 1층**이다.
- 1층 선봉대 보스를 격파하면 **선봉대 + 2층**이, 2층 이단 부대를 격파하면 **이단 + 3층**이, 3층 포병대대를 격파하면 **포병대대 + 4층**이, 4층 특수부대를 격파하면 **특수부대 + 최종 결전**이 해금된다.
- 보스 승리 후에는 바로 런이 종료된다. 다음 구간은 **새로운 런**에서 선택한다. 이것이 v0.2의 층간 자동 진입과 가장 큰 차이다.
- 최종 결전은 **부족의 독재자**와의 한 전투다. 임시 배치 장소이며 원안에서 최종 보스의 위치는 미정이므로 확정으로 보지 않는다.
- 해금 정보는 브라우저의 `chesslayer.progress.v0.3`에 저장된다. 런 내 행동 기록과 별도로 보관한다.
- 런 저장 포맷 버전을 14로 변경했다. v0.2 런 기록과는 호환되지 않으며, 자동 변환·삭제하지 않는다.

## 임시 콘텐츠 — 교체 필수

| 부대 / 적 | 지금 프로토타입에서 대신 사용하는 것 | 다음 구현 |
| --- | --- | --- |
| 수호자 | 기존 16기, 기존 호신용품, 기존 카드 등록 | 수호자 전용 카드·유물풀 구분 |
| 선봉대 | 기존 16기 + 가속 | 도끼·장창 계열 기물, 총격, 민첩/약화, 전용 카드 |
| 이단 부대 | 기존 16기 + **임시** 소용돌이 | 카니발의 신호탄, 시체·식재료·허기·광기·죄책감, 별도 기물, 카드·유물 |
| 포병대대 | 기존 16기 + **임시** 선공권 | 소총수·포격, 공통 명중률, 전용 카드·유물 |
| 특수부대 | 기존 16기 + **임시** 아이스크림 | 특수 사격·기믹, 전용 카드·유물 |
| 1~4층 보스 | 기존 체스 기물로 구성한 구별되는 편성 | 각 보스 부대의 실제 기물·강화 트리·특수 패시브 |
| 부족의 독재자 | 아마존 로얄과 호위 기물 | 독재자 전용 행동·패턴·정식 배치 |

3~4층 일반전·엘리트 전투는 임시로 2층 전투를 재사용한다. 이단 부대의 **식재료 포획 시 공격자 제자리 유지 / 대상 시체화**, **시체 양 진영 포획**, **허기의 전투 간 지속** 등은 엔진에 연결되기 전까지 **작동하지 않는다**. 현재 UI의 부대 선택과 보스 이름만으로 해당 기믹이 구현된 것으로 판단하면 안 된다.

## 코드 구조

- `crates/chesslayer/src/content/characters/mod.rs`: 선택 가능한 부대 ID와 임시 시작 유물
- `crates/chesslayer/src/content/encounters.rs`: 각 층 보스 임시 편성
- `crates/chesslayer/src/map.rs`: 1~4층 보스 지정, 최종 결전 맵
- `crates/chesslayer/src/game.rs`: 보스 승리 시 런 종료, 시작 층 지정
- `crates/chesslayer-web/src/lib.rs`: `WebGame.new_at_floor(character, seed, floor)` 및 저장
- `web/src/main.tsx`: 해금 상태 보관과 새 런 선택 UI

## 확인 포인트

기존 v0.2의 **1층 격파 → 같은 런 2층 진입**을 전제로 작성된 테스트는 v0.3 규칙과 상충한다. 이 변경은 새 런 시작 중심 진행으로 변경된 것을 의도한 것이다. 최초 진입, 보스 승리, 새 런에서 해금된 층 시작, 저장 복원, 최종 결전 승리 순으로 확인한다.

> 원격 `feature/v0.3.0` 브랜치(2026-10-26 v0.2.4 커밋 기반)를 사용했다. 로컬에서 아직 푸시하지 않은 파일은 포함되지 않는다.
