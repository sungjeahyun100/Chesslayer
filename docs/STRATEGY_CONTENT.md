# v0.3.0 신규 카드·유물 구현 메모

이 문서의 전략 방향 용어는 내부 기획에만 사용한다. 플레이어에게는 별도 빌드 분류나 선택 화면을 제공하지 않는다. 신규 카드와 유물은 선봉대와 포병대의 기존 보상 풀 및 도감에 등록한다. ‘인해전술’은 카드의 고유 명칭으로 유지한다.

## 미확정 수치에 적용한 규칙

- 무모한 돌격: 이번 턴에 원래 한 칸의 비포획 행마가 가능한 방향으로, 중간 칸과 도착 칸이 모두 비어 있으면 한 칸 더 이동할 수 있다. 다음 적 턴에 해당 기물이 적에게 포획되면 마나 1을 잃는다.
- 사격 제원 공유: 실제로 명중한 적을 다시 사격하는 다음 아군 사격에 명중률 +15%p.
- 철저한 방어: 사용한 턴에 이동하지 않았으면 다음 자신의 턴에 해당 사수의 명중률 +15%p, 사거리 +1칸. 기본 사거리가 보드 최대 거리보다 짧은 사수만 선택할 수 있다.
- 조준 보정 +25%p와 장약 증량 관통경로 +20%p는 각각 다음 사격 한 번에 적용된다.
- 모든 확률 보정은 합산 후 0~100%로 제한한다.
- 조준 보정·장약 증량을 같은 사수에게 여러 번 사용하면 다음 사격 보너스를 합산한다. 대기형 지속 카드가 이미 활성화된 경우 같은 카드 재사용을 거부해 손패와 자원이 소모되지 않게 한다.

## 구현 및 검증

카드 정의는 `crates/chesslayer/src/content/cards/`에서 각각 관리하며, 전투 효과는 기존 카드 선택·사격·포획 경로를 이용한다. 임시 폰은 영구 로스터에 추가하지 않으며 전투 종료 시 이월되지 않는다. 적 턴 포획 반응은 기존 효과 대상 선택 큐를 사용한다.

최소 검증: `cargo test -p chesslayer --test strategy_content`는 기존 풀 통합과 플레이어 노출 문구, 전투 중 사망한 폰의 부활, 탄도 계산기의 두 번째 사격 보정, 적 턴 선택형 반격과 임시 폰 배치, 집중 포화의 사격 경로를 검사한다. 전체 회귀 검증은 `cargo test -p chesslayer --lib --tests`, 웹 산출물 검증은 `npm run wasm && npm run build`를 `web/`에서 실행한다.

브라우저 검증: `cd web && npx playwright test tests/piece-sandbox.spec.ts`는 기존 테스트장 동작과 신규 유물 선택 및 카드 목록 노출을 확인한다.
