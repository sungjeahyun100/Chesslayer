# Rust 엔진 구조

루트 Cargo workspace에는 `chesslayer-core`, `chessembly`, `chesslayer-rules`가 있습니다. 의존 방향은 향후 UI 또는 WASM 어댑터 → `chesslayer-rules` → `chessembly` → `chesslayer-core`입니다. 현재 전투 모듈은 브라우저 런타임에 의존하지 않습니다.

`chesslayer-core`는 보드, 기물 식별자, 공통 액션 효과 및 `RuleModule` 트레이트를 제공합니다. 모듈별 설정·상태·액션·결과 형식은 각 룰 모듈이 정합니다. `chessembly`는 재사용 가능한 파서와 액션 후보 생성기입니다. 세부 문법과 액션 계약은 [CHESSEMBLY.md](CHESSEMBLY.md)에 있습니다.

`chesslayer-rules`는 전투 입력, 순서가 있는 이동 후보, 액션 적용, 승패 및 다음 전투로 이어질 플레이어 기물 상태를 제공합니다. 전투 종료 조건은 플레이어 킹의 직접 포획에 따른 패배와 지정된 적 왕실 기물의 직접 포획에 따른 승리입니다. 지정 기물의 종류가 킹일 필요는 없습니다. 체크메이트와 스테일메이트는 전투를 끝내지 않습니다. 전투 설정 중 적 배치가 플레이어 기물과 겹치면 해당 플레이어 기물은 전투에서 제거됩니다. 이미 확정된 카드 효과는 별도 진입점으로 적용하며 기물 이동 턴을 바꾸지 않습니다.

현재 정의되지 않은 시스템은 덱·마나·드로우, 개별 카드 효과, 적 AI, 전투 진행, 보상, 지도, 상점, 휴식 선택 및 상태·업그레이드의 구체적인 전투 효과입니다. 전투 입력과 출력은 향후 이 시스템을 연결할 수 있는 경계로 유지합니다. 기본 이동과 남은 특수 이동 결정은 [README](../README.md)에 요약돼 있습니다.
