# 제1막 분기 맵 — 프로토타입 임시 규칙

직선 경로를 제거하고, **런 시작 시 전체 지도를 한 번 만든 뒤 연결된 경로를 선택**하도록 변경했습니다. 아래 수치와 콘텐츠는 플레이테스트용 임시 결정이며 정식 규칙이 아닙니다.

## 플레이 방법

1. 새 게임에서 캐릭터를 선택하고 런을 시작합니다.
2. 아래쪽 세 시작점과 위쪽 보스까지의 전체 경로를 확인합니다. 초록색 노드 또는 오른쪽의 다음 행선지 버튼을 누릅니다.
3. 전투는 적 로얄 포획 후 카드 보상을 고르면 끝납니다. 보물은 수령, 휴식은 강화·부활·건너뛰기로 완료합니다.
4. 지도로 돌아와 현재 노드에서 연결된 다음 노드 하나를 선택합니다. 이미 지나온 노드나 옆 경로로 이동할 수 없습니다.
5. 분기와 합류를 거쳐 보스를 직접 포획하면 승리합니다. 킹을 잃으면 즉시 원정이 끝납니다.

지도에서 현재 위치는 테두리와 `현재` 표시, 완료한 노드는 체크, 선택한 길은 짙은 초록 실선, 다음 길은 굵은 초록 점선입니다. 앞으로 이어질 길도 실선으로 표시합니다. 같은 단계의 노드를 균등한 간격으로 배치해 연결선을 따라가기 쉽게 했습니다. 아직 선택할 수 없는 노드는 비활성화되며 지나친 갈림길은 흐리게 표시합니다. 전투 중 `전체 지도 보기`로 경로를 살펴볼 수 있지만, 현재 콘텐츠를 완료하기 전에는 다음 노드를 선택할 수 없습니다.

## 생성 방식과 보장

- 7단계, 최대 5열, 총 18~20개 노드입니다. 모든 경로는 단계마다 하나씩 선택해 보스까지 7개 노드를 방문합니다.
- 단계별 노드 수는 `3 → 4 → 2 → 3~4 → 2 → 3~4 → 1`입니다. 넓어지는 단계에서 갈라지고 좁아지는 단계에서 합쳐집니다.
- 세 시작점에는 각각 두 개의 다음 노드를 연결합니다. 이후에는 좌우 순서를 보존하는 무작위 연결을 만들어 모든 출발 노드에 출구, 모든 도착 노드에 입구가 있게 합니다. 연결은 바로 다음 단계로만 이어집니다.
- 시작점에서 도달할 수 없는 노드, 막다른 길, 후진 경로는 없습니다. 모든 노드에서 보스로 가는 경로가 있습니다. 전투에서 생존할 수 있다는 보장은 아닙니다.
- 단계별 폭 일부, 연결, 콘텐츠 배치, 적 편성, 유물 보상을 시드로 선택합니다. 단계 구성은 제한된 틀이지만 실제 연결과 선택지는 런마다 달라집니다. 화면 좌표는 단계별 노드 순서에 따라 가운데에 균등 배치하며 경로 연결 자체에는 영향을 주지 않습니다.
- 일반 실행은 `crypto.getRandomValues`의 새 시드를 사용합니다. Rust가 별도 지도 RNG 스트림으로 전체 그래프를 생성하며, 드로우나 AI 행동은 생성된 지도를 바꾸지 않습니다. 노드 진입 때 콘텐츠를 다시 추첨하지 않습니다.
- 저장 기능은 없습니다. 같은 런 안에서는 맵이 유지되지만 새로고침으로 새 런을 시작하면 다른 지도가 생성됩니다.

생성 파라미터는 `crates/chesslayer/src/map.rs`의 `MAP_ROWS`, `MAP_LANES`, `widths`, 단계별 유형 배열에서 수정합니다. 화면의 노드 간격은 `web/src/ActMap.tsx`와 `web/src/style.css`에서 조정합니다. 단계 수를 바꿀 때 배열과 UI의 지도 높이도 검토해야 합니다. 범용 맵 편집기나 설정 프레임워크는 추가하지 않았습니다.

## 실제로 생성하는 노드

| 유형 | 콘텐츠 | 완료 및 보상 |
| --- | --- | --- |
| 일반 전투 ⚔ | 시작점은 킹 2곳·로얄 나이트 1곳을 섞음. 이후 로얄 나이트·비숍 호위 킹·폰 군단 킹 중 선택 | 기존 카드 보상 3종 중 1장 선택 후 지도 |
| 엘리트 ♜ | 마하라자·호드·건어물·런던 중 시드로 선택 | 카드 1장 + 미리 지정된 유물, 지도 복귀 |
| 휴식 ⌂ | 기존 폰 강화·사망 기물 부활·그냥 출발 | 한 번 선택하고 지도 복귀 |
| 보물 ◇ | 미리 지정된 유물 1개 | 수령하고 지도 복귀 |
| 보스 ♛ | e8 구행(로얄) 한 기 | 원정 승리 |

유물 풀은 가속·소용돌이·호신용품입니다. 중복 유물은 가호 카드 1장으로 바꿉니다. 획득 유물은 다음 전투에서 적용되며, 이미 획득한 유물·카드·강화·손실은 다른 노드에서도 유지됩니다. 엘리트는 고유 편성과 추가 보상을 사용합니다. 정확한 좌표와 ID는 [1층 몬스터 편성](content/encounters.md)에 있습니다. 안전한 휴식·보물을 택할지 더 많은 전투 보상을 노릴지 경로에서 선택합니다. 휴식은 모든 경로에 강제하지 않습니다.

상점과 랜덤 이벤트는 구현하지 않았고 **지도에도 생성하지 않습니다**. 골드·상점·새 카드 풀·2막·디버그 UI를 추가하지 않았습니다. 기존 전투 규칙과 Chesssembly는 유지했습니다.

## 검증

[TESTING.md](TESTING.md)에 새 Rust 맵 테스트 2개와 브라우저 테스트의 입력·순서·통과 조건·명령을 기록했습니다. 128개 시드의 그래프 연결성을 검사했고, 실제 브라우저에서 분기 선택과 합류, 일반전·엘리트·보물·휴식·보스 승리까지 확인했습니다. 전체 생성 그래프가 노드 완료 후에도 동일한지, 뒤로 가기·건너뛰기·보상 중 이동을 Rust가 거부하는지도 검사합니다.
