# 원정 지도 생성 규칙

원정은 시작할 때 시드로 전체 지도를 한 번 생성합니다. 각 층의 지도는 7열 × 15단계 격자와 그 뒤의 별도 보스 노드로 구성됩니다. 방문한 노드와 다음 선택지는 저장된 지도에 따라 유지됩니다.

## 경로와 노드

1. 격자의 첫 단계에서 시작 열을 고릅니다. 첫 두 경로는 서로 다른 열에서 시작합니다.
2. 바로 다음 단계의 `x-1`, `x`, `x+1` 열 중 격자 안에 있는 열을 골라 연결합니다. 이를 15단계까지 반복합니다.
3. 이 경로를 총 6번 생성합니다. 겹치는 방과 간선은 하나로 합치며, 각 방은 연결된 다음 방의 인접 리스트를 가집니다. 따라서 실제 시작 방은 2~6개입니다.
4. 모든 15단계 방에서 별도의 보스 노드로 연결합니다. 보스를 이기면 기존 원정 규칙대로 다음 층으로 진행합니다.

| 단계 | 방 유형 |
| --- | --- |
| 1단계 | 일반 몬스터 전투 |
| 9단계 | 보물 상자 |
| 15단계 | 휴식 |
| 나머지 단계 | 일반 몬스터 45%, 이벤트 22%, 엘리트 전투 16%, 휴식 12%, 상점 5% |

일반 단계에서 보물은 생성되지 않습니다. 전투 편성과 보물 유물은 노드 생성 때 선택합니다. 같은 시드와 층에서 지도와 콘텐츠가 재현되며, 지도 생성은 전투 및 덱의 난수 흐름을 소비하지 않습니다.

## 길 표시

화면은 각 격자 노드의 좌표에 시드와 노드 번호로 정한 가로 ±5px, 세로 ±12px의 오차를 줍니다. 오차를 적용한 뒤 가장 왼쪽 노드와 오른쪽 노드를 기준으로 전체 경로를 가로 중앙에 놓습니다. 별도 보스 노드는 중앙에 고정합니다. 방은 원형 테두리 안에 기호로 표시하고, 별도의 출발 지점 표시는 두지 않습니다. 시작 방들에서 깊이 우선 탐색(DFS)을 수행해 인접 리스트의 모든 간선을 수집합니다. 합류 지점은 한 번 방문하지만, 그 지점으로 들어오는 간선은 모두 표시합니다. 각 간선의 두 끝 사이 각도와 거리를 구하고, 픽셀 거리의 `0.12`배를 반올림한 수만큼 점을 만듭니다(최소 1개). 점 위치는 두 끝 좌표를 선형 보간하고, 각 점의 z축 회전에는 시드와 간선·점 번호에서 정한 최대 ±12°의 오차를 줍니다. 방문 경로와 다음 선택지는 기존 색상으로 구분합니다.

생성기는 `crates/chesslayer/src/map.rs`, 길 표시는 `web/src/ActMap.tsx`와 `web/src/styles/map.css`에서 수정합니다. `cargo test -p chesslayer --test act_map`으로 격자와 노드 규칙을 확인합니다.
